# Red por la Equidad – ODS 16

Sitio web educativo de cuatro páginas sobre el Objetivo de Desarrollo Sostenible 16: Paz, justicia e instituciones sólidas. La asociación Red por la Equidad es ficticia.

## Archivos
- `index.html`: portada y presentación.
- `problema.html`: explicación del problema y datos oficiales.
- `soluciones.html`: propuestas y tabla de actuación.
- `participa.html`: acciones para la ciudadanía.
- `style.css`: hoja de estilos común.
- `img/`: ilustraciones SVG propias.
- `prompts.md`: cuaderno de prompts.

## Probar en el ordenador
Abre `index.html` en el navegador. Comprueba los cuatro enlaces del menú y reduce el ancho de la ventana para revisar la versión móvil.

## Publicar con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `red-por-la-equidad`.
2. Sube todos los archivos y la carpeta `img` a la raíz del repositorio.
3. Realiza al menos cuatro commits con mensajes descriptivos.
4. Entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`. Pulsa **Save**.
6. Espera a que GitHub Pages publique la web y copia el enlace que aparece en esa misma sección.

## Antes de entregar
- Escribe personalmente los tres apartados «Mi opinión» (mínimo cuatro líneas cada uno).
- Personaliza el pie de página con tu nombre, sin añadir datos personales como teléfono o dirección.
- Comprueba los enlaces, las imágenes y la versión móvil.
- Revisa que `prompts.md` describa fielmente los prompts y cambios que realmente has hecho.
- Entrega el enlace público de GitHub Pages en Teams.
